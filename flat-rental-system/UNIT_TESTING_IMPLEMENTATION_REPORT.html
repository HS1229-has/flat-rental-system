Introduction

Unit testing was implemented for the Flat Rental System (LuxeFlats) backend to verify that individual services, domain logic, and validation methods operate correctly and reliably in complete isolation. JUnit 5 was utilized as the standard Java testing framework to structure and execute test suites, while Mockito was employed to mock external dependencies such as repositories, security utilities, and inter-service HTTP clients without requiring active MySQL database or network connectivity.

The test suite covers successful core workflows, input validations, exception handling, role-based authorization, state transition guards, and payment processing. A total of 46 test cases were executed across all microservices, and all 46 test cases passed successfully (100% success rate).

Conclusion

The unit testing implementation was successfully completed for all core backend microservices of the Flat Rental System (LuxeFlats). A total of 46 test cases were executed, and all 46 passed with zero failures and zero errors.

The tests validate positive operational paths as well as negative edge cases, including duplicate resource rejection, role-based access security, invalid dates and salary ranges, state machine terminal restrictions, independent token/rent transaction types, and refund flows. Using Mockito dynamic proxies ensured rapid, isolated execution with 100% reproducibility across environments.
